# ChatGPT scheduled task prompts

## 週次: 新着研究ウォッチ

推奨実行日時: 毎週土曜日 08:00 JST

```text
ｽﾀｯｸﾁｬﾝ学術Wikiの新着研究を調査してください。

対象は小型コミュニケーションロボットに関連する学術研究全般です。特に次を含めてください。
- Human–Robot Interaction
- 音声対話、LLM、マルチモーダルコミュニケーション
- 身体性、表情、動作、かわいい、キャラクターデザイン
- 感情、人格、愛着、コンパニオンロボットの長期利用
- 組み込みAI、TinyML、オンデバイス音声・視覚・LLM
- 社会実装、教育、福祉、家庭、展示、接客
- 倫理、プライバシー、サービス終了、修理可能性
- オープンソースハードウェア、Maker文化、ユーザーイノベーション
- OSSコミュニティ、共同保守、知識コモンズ
- 推し活、ファンダム、参加型文化、ファン労働、共同体儀礼

直近14日間に公開または更新された研究を優先してください。
一次情報を確認し、検索結果の断片だけで結果を断定しないでください。

GitHub上のstack-chan research wikiを確認できる場合は、DOI、arXiv ID、CRID、タイトルで重複を除外してください。

候補ごとに以下を出してください。
- タイトル、著者、公開日
- DOI等の恒久ID
- 査読状況
- 研究領域、方法、対象者、環境
- 主な研究課題
- ｽﾀｯｸﾁｬﾝとの関連性
- 採用優先度: 高・中・低
- 一次情報への参照

重要度が中以上の新規候補がない場合は通知しないでください。
```

## 月次: Wikiヘルスチェック

推奨実行日時: 毎月第1日曜日 09:00 JST

```text
stack-chan research wikiの月次ヘルスチェックを行ってください。

確認項目:
- 壊れたWikiリンク、孤立ページ、索引漏れ
- 同一DOI、arXiv ID、CRID、論文タイトルの重複
- candidateのまま30日以上経過した文献
- プレプリントから査読版への更新
- 訂正、撤回、再現性上の重大な更新
- 出典のない学術的主張
- 結果、著者の主張、Wiki編集者の解釈の混同
- ｽﾀｯｸﾁｬﾝへの適用可能性の過大評価
- 分類語彙の重複や表記揺れ
- kawaii、cuteness、baby-schemaの不用意な同一視
- oshikatsu、fandom、participatory-culture等の文化概念の混同
- オープンソース実践と一般的な製品利用の混同

問題を次に分類してください。
1. 機械的に修正可能
2. Agentによる修正候補
3. 人間の判断が必要
4. 新たな文献調査が必要

重大な問題がない場合は通知しないでください。
```

```text
本文は直接変更せず、根拠付きの変更案として報告してください。
```
