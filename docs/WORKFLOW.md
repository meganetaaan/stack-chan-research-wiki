# Wiki maintenance workflow

## 候補の発見

1. 定期検索が `sources/inbox/` に候補を追加する
2. DOI、arXiv ID、CRID、タイトルで重複確認する
3. 優先度を高・中・低で評価する

## 論文の採用

1. 一次情報で書誌情報を確認
2. 抄録または本文を確認
3. `sources/records/` を作成
4. `wiki/papers/` を作成
5. 関連トピックと領域ページを更新
6. `stackchan_relevance` を記載
7. PRを作成

## 人間レビュー

人間は以下を確認する。

- 書誌情報
- 研究方法と結果
- 引用の正確性
- 解釈の強さ
- ｽﾀｯｸﾁｬﾝへの適用可能性
- 著作権

レビュー後のみ `human_reviewed` を設定できる。

## 月次保守

- 壊れたWikiリンク
- 孤立ページ
- candidateの滞留
- DOI重複
- プレプリントから正式版への更新
- 訂正・撤回
- 出典なしの断定
- 分類語彙の重複
- 90日以上更新されていない主要トピック
