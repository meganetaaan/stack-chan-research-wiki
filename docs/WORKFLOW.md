# Wiki maintenance workflow

## 候補の発見

1. OpenAlex、arXiv、ACL Anthologyの定期検索が過去30日間の候補を `sources/inbox/` に追加する
2. DOI、arXiv ID、CRID、タイトルで重複確認する
3. 被引用数、Reddit言及数、X原投稿数を確認する
4. Draft PR本文に表示された最大10件のレビューキューから一次情報を確認する
5. ｽﾀｯｸﾁｬﾝへの関連性を高・中・低で評価する

定量指標を通過した候補でも、関連性が低ければ採用しない。

定量指標を通過しなかった候補は、関連性確認枠で高関連と判断された場合に採用できる。

## 論文の採用

1. 一次情報で書誌情報を確認
2. 抄録または本文を確認
3. `sources/records/` を作成
4. `wiki/papers/` を作成
5. 関連トピックと領域ページを更新
6. `stackchan_relevance` を記載
7. PRを作成

## 人間レビュー

人間は以下を確認する。

- 書誌情報
- 研究方法と結果
- 引用の正確性
- 解釈の強さ
- ｽﾀｯｸﾁｬﾝへの適用可能性
- 著作権

レビュー後のみ `human_reviewed` を設定できる。

## 月次保守

- 壊れたWikiリンク
- 孤立ページ
- candidateの滞留
- DOI重複
- プレプリントから正式版への更新
- 訂正・撤回
- 出典なしの断定
- 分類語彙の重複
- 90日以上更新されていない主要トピック
- 公開後30日と90日を経過した候補の引用数と正式出版状況
