# Repository name candidates

## 推奨

1. `stack-chan-research-wiki` — 内容と形式が最も明確
2. `stack-chan-research-atlas` — 横断的な研究地図という印象
3. `stack-chan-knowledge` — 将来、論文以外の実践知も含めやすい
