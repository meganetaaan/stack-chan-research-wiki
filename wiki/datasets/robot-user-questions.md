# Robot User Questions Dataset

100人がロボットの動画・文章刺激を見て作成した1,893件の質問と、12大分類・70小分類からなる説明要求データセット。

## 用途と制約

説明機能の要求整理、質問分類、評価セット作成に利用できる。質問への正答や、実際のロボット利用中に生じた発話を収録するものではない。
